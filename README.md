# iShop v5.0.0 — React + Vite + Tailwind

نسخة تجربة. المشروع الحالي (Vanilla JS) على Netlify **ما اتلمسش**.

## النشر على Vercel من الآيفون

1. **Working Copy** (تطبيق Git مجاني) → أنشئ مستودع جديد → استورد ملفات الفولدر ده → ارفعه على GitHub
2. من المتصفح: **vercel.com/new** → اختار المستودع → **Deploy**

خلاص. `vercel.json` فيه كل الإعدادات، وVercel هيقرأها لوحده.

**مش محتاج تضبط أي Environment Variables** — مفاتيح Supabase ليها قيم احتياطية في `src/lib/supabase.js`.
(المفتاح ده anon key علني أصلًا — موجود بالنص في `config.js` على الموقع الحي. الحماية في الـ RLS.)

## التشغيل محليًا

```bash
npm install
npm run dev
```

## حاجتين لازم تعرفهم

**1. البيانات حقيقية.** نفس مشروع Supabase. أي حد يفتح الرابط ويسجّل دخول، بيشوف الداتا الحقيقية.
لو ده مقلقك: Vercel → Settings → Deployment Protection.

**2. إعادة تعيين كلمة السر معطّلة على دومين التجربة.**
Supabase بيقبل الرجوع للدومين النهائي بس (`ishop.mtc-group.online`).
ده **مقصود** — عشان ما نلمسش إعدادات Supabase. الميزة هتشتغل تلقائيًا عند التبديل النهائي.
